EziHubb Partner API

Introduction

The EziHubb Partner API lets 3rd-party tools — listing automation, bulk-management apps, custom integrations — manage a seller's own product catalog directly, the same way Shopify's Admin API or Etsy's Open API work. The API is organized around REST. It accepts JSON request payloads and returns JSON-encoded responses, and uses standard HTTP response codes and verbs.

BASE URL
https://api.ezihubb.com/api/v1

Authentication

The API authenticates requests using an API key. Generate one from your Seller Hub under Settings → API Keys — each key is scoped to exactly one store, so a key can never see or modify another seller's catalog. The full key is shown once, at creation time; store it securely.

Send it on every request as the X-Api-Key header.

Example code
GET /partner/products
X-Api-Key: ezhb_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx

Errors & Rate Limits

Errors are returned with a standard HTTP status code and a JSON body describing what went wrong.

StatusMeaning
401Missing, invalid, or revoked API key
404Resource not found, or belongs to a different store
422Validation failed — see message for details
429Rate limit exceeded for this key — see Retry-After header

Rate limits are tracked per API key (not per IP), so automated traffic from one key never affects another key's quota.

Create a product

Method:POST
Endpoint:/partner/products

Creates a new product in your store. Use the API to generate product information — title, price, category, variants, and images.

Request Body
PropertyTypeRequiredDescription
namestringYProduct name.
skustringYUnique SKU.
descriptionstringYFull description.
basePricenumberYBase price.
categoryIdstringYCategory ID.
slugstringAuto-generated from name + SKU if omitted.
shortDescriptionstringShort summary, max 500 chars.
compareAtPricenumberOriginal price, must be greater than basePrice.
isActivebooleanPublish immediately. Default true.
isPersonalizablebooleanWhether buyers can customize this product before ordering. Default true.
isFeaturedbooleanShow in featured/highlighted product lists. Default false.
processingDaysnumberProduction time in days before shipment. Default 3.
tagIds / tagsstring[]Existing tag IDs, or tag names to auto-create.
collectionIdsstring[]Collection IDs to add this product to.
customizationConfigobjectPersonalizer field config (JSON) — same shape used by the storefront customizer.
variantsarrayEach: { name, options, price, sku?, isDefault?, sortOrder? } — one entry per real, priced combination (e.g. one row for "Blonde / S", one for "Blonde / M", etc). If you have 13 colors × 8 sizes, send 104 rows.
etsyVariationSummaryarrayAlternative to variants — pass Etsy's listing-page price-range summary (one entry per variation property, e.g. "Colors" / "Sizes", each option carrying a price_min/price_max range) and it's converted to variants for you. Prices are reconstructed with a best-effort formula and are estimates, not exact — the created product is always forced inactive/draft until reviewed. Ignored if variants is also sent.

Images aren't set here — create the product first, then use Upload images or Attach image URLs. Extended fields (shipping profile, materials, occasions, return policy, etc.) can be set afterward via Update a product.

Note on Etsy data: Etsy's real per-combination inventory (GET /v3/application/listings/{listing_id}/inventory) requires the listing owner's own Etsy OAuth credentials, which most integrations won't have. etsyVariationSummary instead accepts the min/max price range per property value shown on Etsy's public listing page (e.g. "Color: Blonde ($34–$47)") — the only shape realistically available without seller-level API access. Because that summary can't be reconstructed into exact per-combination prices (two values can share the same base price yet have different maximums), products created this way are always created as a draft (isActive: false) — review and adjust prices before activating.

Request Example
Example code
POST /partner/products
Content-Type: application/json
X-Api-Key: ezhb_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx

{
  "name": "Custom Name Mug",
  "sku": "MLH-MUG-001",
  "description": "A ceramic mug personalized with any name.",
  "basePrice": 24.99,
  "categoryId": "cat_mugs",
  "variants": [
    { "name": "11oz", "options": { "size": "11oz" }, "price": 24.99, "isDefault": true }
  ]
}
Request Example — from Etsy's variation price-range summary
Example code
POST /partner/products
Content-Type: application/json
X-Api-Key: ezhb_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx

{
  "name": "Sanderson Sisters Halloween Shirt",
  "sku": "HLW-SHIRT-001",
  "description": "Hocus Pocus inspired vintage Halloween tee.",
  "basePrice": 30.48,
  "categoryId": "cat_apparel",
  "etsyVariationSummary": [
    {
      "property_id": "0",
      "name": "Colors",
      "options": [
        { "value": "Blonde", "available": true, "price": 34.17, "price_min": 34.17, "price_max": 46.75 }
        // ...one entry per color option
      ]
    },
    {
      "property_id": "1",
      "name": "Sizes",
      "options": [
        { "value": "S", "available": true, "price": 30.48, "price_min": 30.48, "price_max": 34.17 }
        // ...one entry per size option
      ]
    }
  ]
}

This is a straight pass-through of the price-range data shown on Etsy's public listing page — copy the variations array directly into etsyVariationSummary with no reshaping needed. The product is created as a draft; open it in admin to review the estimated per-combination prices before activating.

Response

Returns 201 Created with the full product object — same shape as Get a product.

Update a product

Method:PATCH
Endpoint:/partner/products/{id}

Updates an existing product. Accepts any subset of the fields from Create a product — only the fields you send are changed. Returns 404 if the product doesn't belong to your store.

Request Example
Example code
PATCH /partner/products/cljk2p9x40001abcd
Content-Type: application/json
X-Api-Key: ezhb_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx

{
  "basePrice": 22.99,
  "isActive": false
}
Response

Returns 200 OK with the updated product object — same shape as Get a product.

Delete a product

Method:DELETE
Endpoint:/partner/products/{id}

Soft-deletes a product (deactivates and hides it from your storefront). Returns 404 if the product doesn't belong to your store.

Request Example
Example code
DELETE /partner/products/cljk2p9x40001abcd
X-Api-Key: ezhb_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
Response

Returns 204 No Content on success.

Upload images

Method:POST
Endpoint:/partner/products/{id}/images

Uploads image files directly (multipart/form-data) and attaches them to the product. JPEG/PNG/WebP only, max 10 MB each, up to 10 files per request. The first image uploaded becomes the primary image if the product has none yet.

Request Example
Example code
POST /partner/products/cljk2p9x40001abcd/images
Content-Type: multipart/form-data
X-Api-Key: ezhb_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx

images: [file1.jpg, file2.png]
Response

Returns 201 Created with the created image records:

Example code
[
  { "id": "img_1", "url": "https://cdn.ezihubb.com/products/.../file1.jpg", "altText": null, "isPrimary": true, "sortOrder": 0 }
]

Attach image URLs

Method:POST
Endpoint:/partner/products/{id}/images/from-urls

Attaches images you've already uploaded elsewhere (your own CDN, S3 bucket, etc.) by URL — no file transfer needed. Useful when your catalog images already live outside EziHubb.

Request Body
PropertyTypeRequiredDescription
urlsstring[]YImage URLs to attach, max 20 per request.
Request Example
Example code
POST /partner/products/cljk2p9x40001abcd/images/from-urls
Content-Type: application/json
X-Api-Key: ezhb_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx

{
  "urls": ["https://example.com/mug-front.jpg", "https://example.com/mug-back.jpg"]
}
Response

Returns 201 Created with the created image records — same shape as Upload images.

Request Body
PropertyTypeRequiredDescription

Search products

Method:GET
Endpoint:/partner/search

Full-text search with filters and facets — always scoped to your own store. Any storeId passed in the query string is ignored server-side, so a key can never search another seller's catalog.

Query Parameters
PropertyTypeDescription
qstringSearch term.
categorystringCategory slug.
minPrice / maxPricenumberPrice range.
minRatingnumberMinimum average rating, 1–5.
sortstringrelevance, newest, price_asc, price_desc, bestseller, rating, featured.
page / limitnumberPagination. Default limit 48.
Request Example
Example code
GET /partner/search?q=mug&sort=bestseller
X-Api-Key: ezhb_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
Response
PropertyTypeDescription
dataarrayMatching products — same shape as List products.
paginationobject{ page, limit, total, totalPages, hasNext, hasPrev }
facetsobjectAggregate counts: freeShipping, onSale, colors, materials, styles, occasion, holiday, recipient.
appliedFiltersobjectEchoes back the filters that were actually applied.
Response Example
Example code
{
  "data": [
    { "id": "cljk2p9x40001abcd", "name": "Custom Name Mug", "basePrice": 24.99 }
  ],
  "pagination": { "page": 1, "limit": 48, "total": 1, "totalPages": 1, "hasNext": false, "hasPrev": false },
  "facets": { "freeShipping": 0, "onSale": 0, "colors": [], "materials": [] },
  "appliedFilters": { "q": "mug" }
}
