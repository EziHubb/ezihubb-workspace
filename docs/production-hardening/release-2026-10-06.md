## Dependency gate follow-up — 2026-10-07

The first pushed candidate, `1536bbe`, passed CI lint/typecheck/tests, build and browser checks, but both workflows stopped at dependency audit. No production migration or restart was performed for that failed candidate.

The follow-up updates Next.js and its companion packages, Joi, Nodemailer, Sharp, and affected transitive dependencies, including Piscina and shell-quote. Sharp is overridden for transitive consumers too: updating the direct dependency alone left Next.js on the vulnerable version. Audit thresholds and CI gates remain unchanged.

Local audit after the final dependency resolution passed both release gates: runtime had 4 low / 10 moderate findings and no high/critical findings; the full dependency tree had 8 low / 44 moderate / 35 high findings and no critical findings. These are threshold passes, not a claim that all dependency vulnerabilities are resolved.

API/admin/client production builds passed after the final Sharp override. The storefront startup bundle was 166.6 kB gzip (largest shared chunk 71.3 kB), within the existing 225/100 kB budgets. Local builds used synthetic API URLs; production must use CI-built images with its configured environment. The preceding dependency verification passed API 63 suites / 592 tests and API/admin/client/shared-utils lint/typecheck; CI will rerun checks for the final lockfile.
